# 🚀 Personal Developer Portfolio | FUTURE_FS_01

A modern, responsive, and interactive Personal Portfolio website built for **Task 01 (FUTURE_FS_01)** of the **Future Interns Full Stack Web Development Internship**.

---

## 🌟 Features

- 🎨 **Modern Glassmorphism UI**: Sleek dark & light theme design with fluid gradients, neon accents, and backdrop blurs.
- ⚡ **Interactive Background**: High-performance canvas constellation particle animation that reacts to mouse movements.
- 📱 **Fully Responsive Layout**: Seamless experience across mobile, tablet, laptop, and ultra-wide screens.
- ⌨️ **Dynamic Typing Animation**: Dynamic title and skill typewriter effect in the hero section.
- 🛠️ **Categorized & Filterable Projects**: Filter projects by categories (Full Stack, Frontend, Backend, etc.).
- 📊 **Interactive Skills & Experience Timeline**: Visual representations of technical competencies and internship roadmap.
- 📬 **Interactive Contact Form**: Client-side validated form with animated toast notifications.
- 🌗 **Dark / Light Mode**: Instant theme switching with persistent user preference storage (`localStorage`).
- ♿ **Accessible & SEO Optimized**: Semantic HTML5 tags, meta descriptions, and ARIA labels.


## 🚀 Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Thanush231/FUTURE_FS_01.git
   ```
2. Navigate to the project folder:
   ```bash
   cd FUTURE_FS_01
   ```
3. Open `index.html` in your browser (or use Live Server in VS Code):
   - Simply double click `index.html`, or
   - Right-click `index.html` -> **Open with Live Server**.
